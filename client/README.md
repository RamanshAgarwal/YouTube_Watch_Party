# 🎬 YouTube Watch Party — Frontend Client

This is the React frontend for the YouTube Watch Party real-time application.

For complete documentation, system architecture, Socket.IO API schemas, and deployment instructions, please refer to the main [Root README](../README.md).

## Local Frontend Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Environment Variables
Copy `.env.example` to `.env`:
```env
VITE_SERVER_URL=http://localhost:5000
```
